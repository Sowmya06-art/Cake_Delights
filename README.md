# Cake Delights 🍰

A responsive, interactive e-commerce storefront designed for a modern bakery. 

This project was built with a strong emphasis on user interface (UI) design and mobile responsiveness, ensuring a seamless and visually appealing experience across desktops, and tablets.

## ✨ Features
* **Responsive Layout:** Fluid design that adapts perfectly to any screen size using a mobile-first approach.
* **Modern UI/UX:** Clean, intuitive navigation and beautifully styled product displays.
* **Interactive Elements:** Dynamic front-end interactions to enhance the shopping experience.

## 🛠️ Tech Stack
* **Markup & Styling:** HTML5, CSS3
* **Framework:** Bootstrap
* **Interactivity:** JavaScript

## 🌱 Project Journey
**Cake Delights** holds a special place in my portfolio as my very first technical project. Building this storefront was my introduction to the world of web development. It taught me the core fundamentals of structuring the web with HTML, styling with CSS, and bringing pages to life with JavaScript and Bootstrap. 

This project ignited my passion for crafting intuitive user experiences and laid the strong foundation for my continuous journey into full-stack development.
